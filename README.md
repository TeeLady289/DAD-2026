# Dad — Card Game

Dad is the Indiana house game of Clabber, playable in the browser.

2, 3, or 4 players. Play against the computer, with your house rules:
four Jacks are 200, other four-of-a-kinds are 100, a dad is a 3-card run
in one suit, Bella is King and Queen of trumps, first to 500 wins.

Play chips only — no real money, no cash value.

Open `index.html` to play. This site is published with GitHub Pages —
every update to this repo updates the same live link.
